Moon Uploader ホーム

プライバシーポリシー

適用対象：Moon Uploader（Sleep Under the Moon チャンネル運営者専用の Mac 用ツール）

利用する Google データと目的

  • Google Drive API：対象の動画パートを探し、ファイル名、ID、サイズ、チェックサム、ダウンロード権限とファイル内容を取得します。取得した内容は結合と検査に使います。Drive のファイルを変更・削除しません。
  • YouTube Data API：認証したチャンネル名と ID を照合し、運営者が選んだ動画を非公開でアップロードします。動画 ID、公開範囲、処理状況を読み取り、結果を確認します。接続テストでアプリ自身が作成した動画のみ、運営者の確認後に削除できます。

保存と削除

OAuth の認証情報、処理中のファイル、作業を再開するための情報、動画 ID と処理結果は運営者の Mac 上の作業フォルダに保存します。結合済みと確認したローカルのパートは順次削除し、結合動画は YouTube で非公開と処理成功を確認した後にローカルから削除します。中断時のファイルや作業記録は再開や確認のために残る場合があります。

送信先と第三者への提供

アプリは Google の認証、Drive、YouTube の各 API と通信します。アップロード対象の動画は運営者が認証した YouTube チャンネルに送信します。この説明サイトに認証情報や動画を送信しません。アプリが取得した Google データは、広告、販売、AI の学習に使わず、上記の運用以外の目的で第三者に提供しません。

アクセスの取り消し

運営者は Google アカウントの接続設定でアプリへのアクセスを取り消せます。Mac 上に残る認証情報、作業ファイルや処理記録は運営者が削除できます。アクセス取り消しで、Drive や YouTube 上の動画が自動削除されることはありません。

Google API の利用方針

Google API から取得した情報の利用および転送は、Limited Use 要件を含む Google API Services User Data Policy に従います。

お問い合わせ

このアプリに関するお問い合わせは、Google OAuth 同意画面に表示されるサポート先へお願いします。
